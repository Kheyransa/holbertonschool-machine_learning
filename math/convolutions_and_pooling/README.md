# Convolutions and Pooling

This project covers the mechanics of convolutions and pooling operations on images, implemented from scratch using `numpy`. These are the core building blocks behind Convolutional Neural Networks (CNNs).

## Learning Objectives

At the end of this project, you should be able to explain:

* What a convolution is
* What max pooling and average pooling are
* What a kernel/filter is
* What padding is
* What "same" and "valid" padding are
* What a stride is
* What are channels
* How to perform a convolution over an image
* How to perform max/average pooling over an image

## Requirements

* Ubuntu 20.04 LTS
* Python 3.9
* numpy (version 1.25.2)
* All files interpreted/compiled on Ubuntu 20.04 LTS using python3

* All files must be executable
* All code should follow `pycodestyle` (version 2.11.1)
* All modules, classes, and functions must have documentation
