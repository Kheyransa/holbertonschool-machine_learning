# Optimization

This project covers optimization techniques used to train neural networks more efficiently, including normalization, mini-batch gradient descent, gradient descent with momentum, RMSProp, Adam, learning rate decay, and batch normalization.

## Learning Objectives

By the end of this project, you should be able to explain:

* What is a hyperparameter?
* How and why do you normalize your input data?
* What is a saddle point?
* What is stochastic gradient descent?
* What is mini-batch gradient descent?
* What is a moving average? How do you implement it?
* What is gradient descent with momentum? How do you implement it?
* What is RMSProp? How do you implement it?
* What is Adam optimization? How do you implement it?
* What is learning rate decay? How do you implement it?
* What is batch normalization? How do you implement it?
