# 0x0A. Object Detection

This project covers object detection using the YOLO v3 algorithm,
including:

* Initializing a Yolo model from a pre-trained Darknet Keras model
* Processing model outputs into bounding boxes
* Filtering boxes by class score threshold
* Applying non-max suppression
* Loading and preprocessing images for detection
* Displaying detection results

## Files

* `0-yolo.py` - Defines the `Yolo` class used to perform object
  detection with the Yolo v3 algorithm.
